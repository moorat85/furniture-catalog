# Каталог — рабочая база моделей (черновик)

Личный минималистичный инструмент: слева — навигация (закреплённый пункт
«Стандарты» + список моделей), справа — страница модели (3D-заглушка,
чертежи, спецификация) или сама страница стандартов.

## Структура

```
site/
├── index.html
├── css/style.css
├── js/app.js
├── data/standards.json   — справочник параметров и правил по категориям
└── data/models.json      — модели, каждая ссылается на ключи из standards.json
```

## Как это связано

У каждой модели в `models.json` есть `linkedStandards` — список ключей
параметров из `standards.json`. На странице модели они показаны как чипы;
клик по чипу ведёт на страницу «Стандарты» и подсвечивает нужную строку.

Пока изменение `standards.json` не пересчитывает модели автоматически —
это заложено на будущее, когда появится полноценное редактирование
стандартов в интерфейсе.

## Посмотреть локально

```bash
cd site
python3 -m http.server 8000
```

Открыть http://localhost:8000 (напрямую через file:// не заработает — данные грузятся через fetch).

## Код на входе

Сайт публичный (GitHub Pages), поэтому перед каталогом стоит экран с
4-значным кодом — `js/auth.js`. Поле ввода невидимое, фокус ставится
сразу при заходе, вводятся только цифры, проверка — как только введены
все 4. Это НЕ настоящая защита (код проверяется в браузере), а просто
барьер от случайных посетителей.

Как сменить код — написано прямо в комментарии в начале `js/auth.js`
(коротко: посчитать SHA-256 нового кода и вставить хэш вместо
`PIN_HASH`; если нужна другая длина — поменять `PIN_LENGTH` и число
`.pin-dot` в `index.html`).

## Это черновик

Данные в `standards.json` и `models.json` — примерные, для проверки
структуры и связей. 3D-вид и чертежи — заглушки.
